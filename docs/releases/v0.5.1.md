# Time Series Explorer v0.5.1

Live Update that keeps up: plots following a growing file are redrawn in place instead of being rebuilt on every read, so the app stays responsive and a hover or a drag is no longer cut every two seconds. "Expand if needed" now leaves headroom above a rising signal.

## Downloads

- **Windows 10/11 x64:** installer and portable EXE.
- **macOS Intel:** DMG installer and ZIP package.
- **macOS Apple silicon:** DMG installer and ZIP package.
- **Linux x86_64:** DEB installer and AppImage package.
- **SHA256SUMS files:** checksums for verifying the downloaded packages.

The executables are currently unsigned. Verify that the file was downloaded from the official Time Series Explorer download button and compare its SHA-256 checksum before running it.

- **Windows:** SmartScreen may show an **Unknown publisher** warning. Choose *More info* → *Run anyway*.
- **macOS:** Gatekeeper refuses an unsigned, un-notarized app with *"Time Series Explorer" cannot be opened*. Open **System Settings → Privacy & Security**, scroll to the message naming the app, and click **Open Anyway**; then confirm in the dialog that follows. On macOS Sequoia this panel is the only route — right-click → Open no longer offers the override.

## Live Update

- **Plots redrawn in place.** Each read of the file used to tear down and rebuild every time plot drawing it. A time plot now takes the new rows the way it takes a pan: the same chart, new data and the new view in one redraw. On a 20,000-row, 108-column logger file shown on six plots, the app was busy for about three quarters of a second out of every two; it is now about a quarter of a second.
- **Nothing you are doing on a plot is interrupted** by a read: a hover, a drag or a zoom carries on. A read is not a step of Ctrl+Z, and does not move the other plots through the axis link (each one follows the policy chosen in the Live menu).
- Plots on very large files opened through DuckDB, the analysis modes, and plots drawn with downsampling off are still rebuilt as before.
- **Expand if needed** grows the Y axis on the side the new data crosses, with the same 5 % headroom an added trace gets, so a rising signal is no longer drawn along the frame; the right axis follows the same rule. On a file opened through DuckDB it expands once more from the values actually drawn, so a peak missing from the overview still fits.
- The Y option that keeps the view is labelled **Manual / user view**, like the X one.

## Plots

- Plots on a calendar time axis prepare their points faster, which also helps every zoom and pan.

## Desktop capabilities

- Fully local, offline application and bundled processing libraries.
- External documentation links open in the operating system's default browser.
- No classic Electron menu or secondary Electron browser windows.
