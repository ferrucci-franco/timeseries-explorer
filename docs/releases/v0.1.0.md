# Time Series Explorer v0.1.0

First release of the Full Desktop edition out of beta, for Windows, macOS and Linux.

## Downloads

- **Windows 10/11 x64:** installer and portable EXE.
- **macOS Intel:** DMG installer and ZIP package.
- **macOS Apple silicon:** DMG installer and ZIP package.
- **Linux x86_64:** DEB installer and AppImage package.
- **SHA256SUMS files:** checksums for verifying the downloaded packages.

The executables are currently unsigned. Windows SmartScreen may therefore show an **Unknown publisher** warning. Verify that the file was downloaded from the official Time Series Explorer download button and compare its SHA-256 checksum before running it.

## New since beta.10

- **Plot the time axis.** Drag the time axis onto a plot to create a derived "sample index" signal (0, 1, 2, …) that visualizes the shape of the time vector — repeated timestamps (events) show up as vertical steps. It behaves like any derived variable (removable, editable with Data Tools, saved in sessions) and works for every format, including lazy files (computed over the loaded overview).
- **Stairs line shape.** Right-click a series in the legend to switch it between a straight (linear) line and stairs (steps) — helpful for discrete or sampled variables. The measurement cursor's intersection dot follows the step, and the change is preserved with the session.
- **Discrete difference.** A new `diff(x)` formula function and a **Difference Δy (no ÷Δt)** method in the Derivative data tool compute plain neighbour differences without dividing by Δt, so duplicate timestamps no longer blow up. `diff(time)` reveals the sampling shape (Δt), `diff(diff(time))` is zero for uniform sampling, and the time axis is now offered in the formula autocomplete.
- **Per-axis auto-fit everywhere.** The **Fit X** / **Fit Y** buttons now also appear in the analysis modes — FFT, Histogram, Temporal profile and Correlation get both; Heatmap gets Fit X (its vertical axis is a fixed categorical axis) — each fitting the analysis pane.
- **Safer examples.** Loading a project example replaces the whole workspace, so it now confirms whenever any file is loaded — no more silently discarding your loaded files — and says plainly that all files and plots will be replaced.
- **Desktop path helpers.** In the Full Desktop app, the *Copy OpenModelica temp path* and *Copy Dymola directory* actions build an exact, per-platform path with your real user name (no USERNAME placeholder) and drop the browser-only guidance.
- **FFT on event data.** Sampling that is uniform apart from a few duplicated event timestamps (a fraction of a ULP up to a tiny event epsilon apart) is no longer rejected as *not uniform*; near-duplicate timestamps are collapsed before the transform.
- **Dymola units.** Dymola variable descriptions that embed clock/type metadata inside the unit bracket (e.g. `[rad/s:#(clock=…)]`) now show a clean unit instead of the raw metadata, in both the variable tree and axis labels.

## Desktop capabilities

- Fully local, offline application and bundled processing libraries.
- External documentation links open in the operating system's default browser.
- No classic Electron menu or secondary Electron browser windows.
- Native local-file access and Live Update.
- Higher loading limits and support for large CSV/TXT and Parquet data.
- MATLAB MAT v4 through v7.3 import, including selective matrix import and independent indexes.
- CSV/TXT, Parquet, Excel, generic and PyPSA netCDF and supported pandas Pickle files.
- Time plots, phase plots, 2D curve fitting, state animation, FFT, histograms, correlation, heatmaps and data tools.
- View/session saving and complete-project ZIP saving for in-memory files.

## Requirements and limitations

- Windows 10 or Windows 11, x64.
- macOS Intel or Apple silicon.
- Linux x86_64.
- No Internet connection is required after installation.
- Complete-project ZIP export is intentionally unavailable while any loaded source is using lazy loading.
- Automatic updates are not included in this release. Download newer releases manually from GitHub.

Please report reproducible problems in the [GitHub issue tracker](https://github.com/ferrucci-franco/timeseries-explorer/issues).
