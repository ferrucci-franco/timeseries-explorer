# Time Series Explorer v0.2.0

Four new Data Tools, an Integral analysis, audio recordings as signals, one export dialog for every panel — and analyses that stay usable on files far larger than memory.

## Downloads

- **Windows 10/11 x64:** installer and portable EXE.
- **macOS Intel:** DMG installer and ZIP package.
- **macOS Apple silicon:** DMG installer and ZIP package.
- **Linux x86_64:** DEB installer and AppImage package.
- **SHA256SUMS files:** checksums for verifying the downloaded packages.

The executables are currently unsigned. Verify that the file was downloaded from the official Time Series Explorer download button and compare its SHA-256 checksum before running it.

- **Windows:** SmartScreen may show an **Unknown publisher** warning. Choose *More info* → *Run anyway*.
- **macOS:** Gatekeeper refuses an unsigned, un-notarized app with *"Time Series Explorer" cannot be opened*. Open **System Settings → Privacy & Security**, scroll to the message naming the app, and click **Open Anyway**; then confirm in the dialog that follows. On macOS Sequoia this panel is the only route — right-click → Open no longer offers the override.

## Four new Data Tools

- **Fill NaN values.** Holes are filled by the method you pick, and the panel says up front what it will do and what it cannot: a gap at the very start has nothing before it to interpolate from, and it says so instead of inventing a value.
- **Resample.** Puts a signal on a uniform grid, completes the timestamps the file skipped, and states where the Δt came from — read from the data or typed by you. Whether a gap is bridged or left as NaN is your decision, not a default hidden in the code.
- **Detrend.** Straight line, mean, polynomial, moving-average baseline, or zeroing the first sample. It reports the drift it removed, per second when the axis has a unit and per sample when it does not.
- **Digital filter.** Coefficient-driven FIR/IIR, forward or forward-and-back for zero phase, with the initial conditions spelled out as a question you can answer — steady state, at rest, a level held before the recording, or the actual past samples. Past inputs and past outputs get a box each, newest first, so their order is something you can see rather than something you have to be told. The help explains what a non-causal pass costs you, and why a filter defined per sample has no fixed cut-off frequency on an irregular Δt.

The Data Tools panel itself was rebuilt around them: each tool starts from its own defaults instead of inheriting the last one's, the buttons have a box of their own, deleting a transformation asks in the row rather than in a dialog, and the panel reports what it did rather than writing silently.

## Integral analysis

- **One bar per signal, totalled over the visible range**, with a pie beside it for the share each signal takes. Both are exported from the same dialog as everything else.
- **Missing data is a policy, not an accident.** A gap can contribute nothing, be crossed by interpolation, or turn the result into NaN from that point on — and the panel says which was applied and how much time was missing, so a lower bound is never presented as a total.
- **Units can be overridden** when the file never declared one, instead of the app calling an undeclared unit "hours".
- Lazily loaded files are totalled too, and the panel says what the total averages out to.

## Audio recordings

Recordings open as one signal per channel on an elapsed-seconds axis built from the file's own sample rate: `.wav`, `.mp3`, `.m4a`, `.flac`, `.ogg`, `.opus`, `.aiff`, `.3gp`, `.webm` and more, which covers phone voice memos from both iPhone and Android. A *Recording* node in the variable tree carries the sample rate, channel count, duration and format. WAV is decoded by the app itself; every other container goes through the browser's decoder at the rate written in the file, not the rate of the sound card. Because a small file can decode into a very large one, the size limit for audio is measured on the decoded samples and asked about after decoding.

## Export a panel

The panel's CSV button is now one **export dialog**: CSV, PNG or SVG from the same place, for the time series and for every analysis chart including the three Integral ones. The figure is exported in a theme rather than merely on a background, and the section documenting it in Help was rewritten around the dialog.

## Large files stay usable

- **Every analysis is bounded.** FFT, histogram, calendar heatmap, temporal profile, correlation, curve fitting, the definite integral and the 2D state animation now work against a measured budget instead of trying to consume the whole range. Multi-gigabyte audio is analysable; the window keeps responding while it happens.
- **A refused FFT range is replaced by the largest one that fits**, not by the last one that worked, and the app says how many samples it actually transformed. When a combination of settings is impossible, the previously accepted settings come back.
- **Ranges the app chooses for you stay draggable.** An automatic block spanning six seconds of a ten-minute axis used to be drawn a few pixels wide, with both edges inside one grab tolerance — the range control stopped working at exactly the moment the app took the decision.
- **An analysis opens on its own view**, not on the zoom the previous mode left behind.
- **Gridded netCDF loads in part instead of being refused.** Evenly spaced points are taken along each dimension within a value budget shared fairly across the file, and the app names which variables were thinned and by how much — with the warning that a subset is enough to see the shape of a field but is not a statistical sample of it.
- **The MAT inflate is bounded by memory**, not by a compression ratio no reader can judge in advance.
- **Sampling uniformity is judged against what the numbers can represent**, and against the median step rather than the mean, so a file with one long gap is no longer called irregular. Each sample owns its own step, which is why 32 whole days now read as 32 days.

## Desktop

- **The window has a zoom again.** Removing the Electron application menu had silently removed the Ctrl +, Ctrl − and Ctrl 0 accelerators with it, and the desktop build was the one place with no browser zoom to fall back on. Zoom now has its own row in the menu and the shortcuts work, scaling the whole window so the plots re-lay-out with it.
- The portable zip ships one launcher instead of several, and the port probe no longer cries wolf.

## Privacy

Google Analytics is gone, replaced by GoatCounter on the web version only. It stores nothing in the browser — no cookies, no `localStorage`, no cache — and keeps no IP addresses or tracker IDs, so there is no consent banner and nothing to opt out of. The Desktop and portable builds never load it.

## Security

- A pandas pickle can no longer execute code while being read, and a malformed MAT file can no longer eat the tab.
- An exported CSV cannot smuggle a formula out of the file it came from.
- Signal names are escaped where they were interpolated into summaries.
- The local-file server refuses a request that does not address it as loopback.
- Release tests run before `main` deploys, and the release token is no longer handed to jobs that execute dependency code.
- The patched dependencies were lifted, and the Node version the project actually needs is pinned in one place for both release paths.
- A dead 941-line copy of the CSV time detector and a 3.6 MB Plotly a full major out of date were deleted; both had been shipping in every web deploy and every installer.

## Fixes

- A signal no longer disappears when the language is changed mid-redraw of a large trace.
- A panel's chart is torn down before a re-render throws its element away.
- The 2D state animation has the pan gestures every other 2D plot already had, and a failed view restore no longer takes them with it.
- The partial-load dialog stays on the screen it was drawn on.
- Missing/NaN bands are repainted when a legend toggle hides a trace.
- Repeated timestamps are accepted when filling and resampling.
- A reload that served stale bytes says so, and a failed bootstrap can be retried; the DuckDB view a reload abandoned is given back.
- The Filter panel's collapse actually collapses, and a configuration that fails to read takes its preview down instead of leaving the last valid curve on the plot — for every tool, not only the filter.
- The sampling time is stated in the Recording details, next to the rate it restates.
- Curve Fit and Correlation open on the same view as every other mode.
- Line endings are decided in `.gitattributes` and the assumption is guarded in CI.

## Desktop capabilities

- Fully local, offline application and bundled processing libraries.
- External documentation links open in the operating system's default browser.
- No classic Electron menu or secondary Electron browser windows.
