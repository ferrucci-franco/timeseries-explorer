# Time Series Explorer v0.5.0

Tabs and a Dashboard: several screens of panels over the same open files, each one coming back as it was left, and a panel mode that shows each signal as a card with its value, live or at an instant picked on the plots. Feedback is now sent with one button, and a saved view opens on other files.

## Downloads

- **Windows 10/11 x64:** installer and portable EXE.
- **macOS Intel:** DMG installer and ZIP package.
- **macOS Apple silicon:** DMG installer and ZIP package.
- **Linux x86_64:** DEB installer and AppImage package.
- **SHA256SUMS files:** checksums for verifying the downloaded packages.

The executables are currently unsigned. Verify that the file was downloaded from the official Time Series Explorer download button and compare its SHA-256 checksum before running it.

- **Windows:** SmartScreen may show an **Unknown publisher** warning. Choose *More info* → *Run anyway*.
- **macOS:** Gatekeeper refuses an unsigned, un-notarized app with *"Time Series Explorer" cannot be opened*. Open **System Settings → Privacy & Security**, scroll to the message naming the app, and click **Open Anyway**; then confirm in the dialog that follows. On macOS Sequoia this panel is the only route — right-click → Open no longer offers the override.

## Tabs

- **Several screens of panels** over the same open files, in the top bar between the title and its buttons, in Full Desktop and in the browser alike. **+** adds a tab; a double-click or F2 renames it; a right-click renames, duplicates or closes it, or closes all tabs after saying how many go; dragging reorders them.
- **Keys:** Alt+1…8 go to a tab and Alt+9 to the last, in both editions (Option+1 on a Mac too). Full Desktop adds Ctrl+T, Ctrl+W, Ctrl+Tab / Ctrl+Shift+Tab, Ctrl+PageDown / PageUp and Ctrl+1…9, which in a browser belong to the browser's own tabs.
- **A tab comes back as it was left:** its charts are kept, so coming back computes nothing again (a spectrum, a correlation, a fit). It is redrawn only when its files, their data or a plot setting changed meanwhile. Up to twelve tabs are kept this way, within the browser's budget of WebGL charts.
- **Many tabs:** they scroll in their own row while the buttons beside them stay put, with a fade at either end, a slim scrollbar, the mouse wheel, and a ▾ list of every tab with its shortcut.
- A saved view keeps every tab with its name, and opens with all of them in either edition.

## Dashboard

- **A panel mode beside the time series** (the gauge button): each signal of the panel is a card with its value — the last one read, which Live Update keeps current (the cards say LIVE), or the one at an instant picked on the time slider under them. **Latest** goes back to following the last value.
- **The instant on the plots:** a dashboard held at an instant draws it as a vertical line on the time plots; dragging the line moves the dashboard, a double-click goes back to Latest.
- **Cards:** a title, a description under it, a unit, decimals, a width of one to three columns, and a background among 28 colours or one's own. They are reordered by dragging, or from the card's editor with the keyboard or on a touch screen. Text signals get a card too.
- **Separators:** a right-click puts in a titled, coloured separator, which groups the cards that follow it.
- A card's unit is the signal's, so the plots, the hover and the statistics show it too. Everything is saved with the view and the tabs. The phone layout offers the dashboard among its plot types.

## Views on other files

- A view saved with a file that is not open, or matched to another file only because it has the same signals (a logger that names its files by the hour), opens a dialog naming the file it was saved with and offering the open files in its place. Its CSV parsing applies to the file picked, and the signals that file lacks are listed.

## Plots and the top bar

- **Shift+click** in the Marks menu (NaN/Inf, Gaps, Repeated, Samples) or on the line shape in the View menu gives every time plot, those of the other tabs included, the state just picked; a plain click still changes one plot.
- The four language buttons are one button with the current language and a menu under it.

## Feedback

- **One Send button:** a report and its screenshots are filed as a GitHub issue without an account or a mail client; the app answers with the issue's link. A failed send keeps the manual ways out.
- **Ctrl+V** attaches a screenshot from anywhere in the form, and a file can be dropped anywhere on it. Large screenshots are re-encoded before they are sent.
- **Full Desktop** never sends anything itself: Feedback explains, then opens the form in the web version in your browser, with this build's version and platform.

## Fixes

- **Live Update:** starting it again after a pause carries on from where it stopped reading, instead of reading the appended rows a second time and stopping on "New rows must have strictly increasing time values".
- Saving a complete project after Live Update had appended rows and the file was reloaded no longer cuts the archived file where Live Update had stopped reading.
- A file dragged from the desktop and dropped over a tab now opens, instead of moving the first tab there.
- A unit set on a formula, data-tool or derived-dataset signal is kept when a view is applied and saved.

## Desktop capabilities

- Fully local, offline application and bundled processing libraries.
- External documentation links open in the operating system's default browser.
- No classic Electron menu or secondary Electron browser windows.
