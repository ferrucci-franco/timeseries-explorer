# Time Series Explorer v0.7.0

Files of any size now get the whole toolbox: every **Data tool**, the **Histogram**, the **calendar heatmap** and the **temporal profile** run over every row of a file opened in memory-saving mode, and their results can be **kept on disk** from one session to the next. The **CSV reader** was rebuilt against a corpus of 144 real instrument files — encodings, separators, preambles, units rows — and now reads them right the first time in 95.5 % of cases. Text columns are drawn as **state bands** along time, the phone layout gains **Data tools** and **Derived variables** of its own, Excel workbooks show as **one file with their sheets**, and the interface speaks **Chinese**.

## Files of any size

- **Every Data tool on a memory-saving file.** The spike detector, the interpolation of outliers, the fill of missing samples and the integral bridging holes run a chunk at a time, bit for bit with the in-memory results. **Resample** and **collapse of repeated timestamps** produce a new memory-saving dataset of their own, written to a table and never held in memory; a 20 M-row collapse fits. The **cross-correlation** reads the two columns into memory up to 8 M rows and says why when a file is longer.
- **Histogram** counts every row of the file, with the same stats, edges and counts as the in-memory histogram.
- **Calendar heatmap and temporal profile** are exact on every axis, including a time axis generated from an origin date and a numeric axis promoted to a calendar, and over derived signals.
- **Results on disk.** Where the browser offers private file storage (a browser tab and the desktop app), the DuckDB database lives in a file and pages out what does not fit in memory. Results are **kept between sessions**: the same tool over the same file in a later session — a reload, a restored session, the file opened again — is reused instead of run again. **Settings** shows what is kept and can delete it. A private (incognito) window holds far less than it reports; the app measures what it really holds and refuses a job that would not fit rather than stalling.
- **Live update continues** a chunked job from where it stopped instead of running it again from the first row at every append.
- "Complete missing timestamps" is offered on memory-saving files, and **Save as file** of a memory-saving dataset is written a chunk at a time, with no limit but the disk's.

## CSV reading

- **Real-world corpus.** 144 files written by real instruments, loggers, PLC/SCADA systems and scientific software are now part of the tests. Right first time: **82.6 % → 95.5 %**, against about 25 % for CleverCSV and pandas. On the public CSV_Wrangling benchmark the delimiter detection scores 96.8 % on held-out files against 95.2 % for CleverCSV, and is 15× faster.
- **Encodings:** BOM sniffing, UTF-16 LE/BE with or without BOM, Shift_JIS, EUC-KR, GBK/Big5, Windows-1250/1251, DOS 866 and KOI8-R. Invisible characters (NUL padding, zero-width spaces, stray BOMs) are removed and counted.
- **Numbers:** decimal and thousands separators detected from unambiguous cells, quoted decimal commas, space/apostrophe grouping, typographic minus, hex values; `NULL`, `None`, `N/A`, `#N/A` and dashes are missing values.
- **Dates:** comma milliseconds, weekdays, UTC offsets, month names in seven languages, 12-hour clocks, `24:00`, two-digit years.
- **Layout:** quoting detected once the delimiter is known; a stray quote no longer swallows the rest of the file; trailing delimiters tolerated; a logger's title line, column names, units row and spacer above the data are read as such; building-management exports with mixed line ends; files of words and codes no longer fall back to a comma.
- **The three readers agree.** The in-memory reader, DuckDB on the whole file and DuckDB on a memory-saving file now read 182 test files identically — types decided over the whole file, the same date rules, the same numbers, the same row order. A column empty in the first rows (a channel that starts late, or never records) is read as numbers, not text.
- **Parsing dialog:** each column header says what it will become (`123`, `abc`, `time`), and the Columns list lets you choose **auto, number or text** per column — keep `001` as `001`. Hovering a cell shows its raw text, its parsed value and its type. New thousands-separator option, 18 encodings with *Auto* naming what it found, the exact detected date pattern, 1000 or all lines shown.

## State bands for text columns

- A text column dropped on a time-series panel (CSV, memory-saving or Parquet) is drawn as a **flat band in its own lane** under the curves, changing colour where the value changes — a machine's state, a mode, an alarm.
- One colour per value across a panel, labels inside the runs, shared hover and the A|B readout read the value at the instant; Shift+click on a lane label removes it. Works on memory-saving files, with exact runs when zoomed in.

## Data tools

- **Edge interval and rate** (new): between two consecutive edges of a signal — rising, falling or both, through a dead band — gives the **interval Δt** or the **mean rate ΔY/Δt**. On a cumulative counter that is the mean power of an energy meter between two of its steps. Placed at the closing edge as dots, or **held over the interval** as stairs whose integral gives the counter back. Runs on memory-saving files too.
- The **pencil** now appears on every derived variable in the tree, Data tools outputs included, and opens its recipe.
- The live preview redraws when the result's look changes (dots or stairs), and only the latest run draws.

## Phone and tablet

- **Data tools on the phone:** a hub of tiles in four families, a page per tool at half height so the preview is watched on the plot above it, big controls, and the file's transformations as cards.
- **Derived variables on the phone:** a formula page with its own keys (+ − × ÷ ^ ( )), variable and function tabs, a calculator pad and a live preview — without the system keyboard. Keys write at the cursor on iOS.
- **Analyze** leads each analysis with a drawing. One set of controls across every sheet and dialog: same fields, sliders, segmented buttons and help icons.
- Sideways, a pill on the right edge brings a hidden sheet back.
- Overlay legends get a **show/hide button** and no longer squeeze the plot.

## Plots

- A panel's first curve opens on the **time window its linked panels show**; a record outside that window widens it for all of them instead of opening on an empty chart.
- The vertical fit of a **stacked** panel with two files now matches the stack actually drawn.

## Excel workbooks

- A workbook with several sheets is **one row in the file list**, with its sheets beneath it. On opening, one switch per sheet (plus *All sheets*) chooses which to read; the others stay listed and open with a click. The active workbook and sheet are highlighted together. Saved sessions regroup.

## Gridded map

- **atlite cutouts** open on the map: longitude and latitude given as auxiliary coordinates of `x` and `y` dimensions are recognised, preferring those a file declares in its CF `coordinates` attribute (#298).

## Languages

- **Simplified Chinese (中文)** joins English, French, Spanish and Italian, with Chinese dates, weekdays and months in the plots.

## Fixes

- Memory-saving CSV with thousands separators or decimal commas lost its values after the first view; every later query now reads the same format.
- An empty bound in hard bounds was read as 0, so a minimum with no maximum flagged every positive value.
- Hard bounds on a memory-saving file failed to create.
- Editing a transformation disarms a pending delete on another.
- Stretched buttons in choice dialogs on the phone layout; the Number format label no longer paints over its select on a phone.

## Desktop capabilities

- External documentation links open in the operating system's default browser.
- No classic Electron menu or secondary Electron browser windows.
