Linear A straight line in time between the samples either side of the hole.

Smoothed local trend Fits a weighted straight line through the surrounding samples, so a noisy signal is bridged along its trend instead of between two noisy readings.

Digital filter help
What it computes a₀·y[n] = b₀·x[n] + b₁·x[n−1] + … − a₁·y[n−1] − … . Leave a at 1 for an FIR.
Stability An unstable filter cannot be created: its own output feeds back and grows until every later sample is infinite. The poles of a are checked before anything runs.
Forward and back (zero phase) Filters twice in opposite directions, so nothing shifts in time — at the cost of applying the magnitude response twice.
Missing data Each run of present samples is filtered on its own, so one hole cannot poison the rest of the signal. Fill the holes first to filter across them.

Resampling help
Reading the curve Linear, cubic, nearest and hold read the signal at each new time. Right for upsampling; downsampling this way aliases fast detail into slow structure.
Reducing a bin Average, median, minimum and maximum reduce every sample around each new time. Average is the anti-aliased downsample; minimum and maximum keep the envelope.
Missing data A hole stays a hole: an empty bin, or a new time surrounded by missing samples, comes out missing. Fill it first if you want it bridged.
A new file The result has its own time axis, so it arrives as a new file next to this one rather than as a variable inside it.
